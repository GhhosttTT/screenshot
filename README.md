# Screenshot Extension - 快捷键截图插件

一个简单高效的 Chrome 浏览器截图插件，支持快捷键操作和批量截图。

> **项目状态**: ✅ 开发完成，可直接使用

## 功能特性

- 🎯 **区域选择**: 拖拽鼠标选择截图区域
- ⌨️ **快捷键操作**: 快速截图，无需鼠标点击
- 👻 **非侵入式**: 遮罩层不阻止页面交互
- 📁 **自动保存**: 截图自动保存到桌面文件夹
- 🔄 **批量截图**: 支持连续截图，无需重新选择区域
- ⚙️ **可配置**: 自定义快捷键、保存路径、图片格式等

## 安装方法

### 方式一：开发者模式加载（推荐用于测试）

1. 打开 Chrome 浏览器
2. 访问 `chrome://extensions/`
3. 启用右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择本项目文件夹 `e:\study\ppt-content-extractor`
6. 插件安装完成！

### 方式二：打包安装

```bash

cd e:\study\ppt-content-extractor
# 将整个文件夹压缩为 .zip 文件
# 在 Chrome 扩展页面拖拽 .zip 文件安装
```

## 使用说明

### 快捷键

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+Shift+Q` | 激活/停用遮罩层 | 显示或隐藏截图区域选择界面 |
| `Ctrl+Shift+S` | 截图 | 截取选定区域并保存 |
| `Ctrl+Shift+K` | 锁定/解锁遮罩层 | 切换调整模式（锁定后可点击下方元素） |
| `Ctrl+Shift+X` | 清除遮罩层 | 移除当前选择的区域 |

*Mac 用户请将 `Ctrl` 替换为 `Command`*

### 基本流程

1. **激活插件**
   - 按 `Ctrl+Shift+Q` 或点击插件图标选择"激活遮罩层"
   
2. **选择区域**
   - 在页面上拖拽鼠标选择矩形区域
   - 释放鼠标后显示半透明遮罩层
   - 可以拖拽边缘的手柄调整区域大小

3. **截图**
   - 按 `Ctrl+Shift+S` 截取当前区域
   - 截图自动保存到桌面的 `Screenshots_日期` 文件夹
   - 显示绿色闪烁效果表示成功

4. **批量截图**
   - 保持遮罩层显示
   - 操作页面（如翻页、滚动）
   - 重复按 `Ctrl+Shift+S` 截图
   - 每次截图自动生成唯一文件名

5. **锁定遮罩层（可选）**
   - 按 `Ctrl+Shift+K` 锁定遮罩层
   - 锁定后可以点击遮罩层下方的页面元素
   - 边框变为绿色表示已锁定
   - 再次按 `Ctrl+Shift+K` 解锁以调整区域

6. **完成**
   - 按 `Ctrl+Shift+X` 清除遮罩层
   - 或按 `Ctrl+Shift+Q` 隐藏遮罩层（保留区域）

## 配置选项

右键点击插件图标 → 选项，可以配置：

- **保存路径**: 桌面或下载文件夹
- **图片格式**: PNG 或 JPG
- **图片质量**: 1-100（仅 JPG）
- **遮罩层颜色**: 自定义颜色和透明度
- **显示尺寸**: 是否显示区域尺寸信息

## 常见问题

### Q: 为什么截图是空白的？
A: 某些网页（如 Chrome 内部页面）不允许截图。请在普通网页上使用。

### Q: 快捷键不起作用？
A: 检查是否与其他软件冲突。可以在设置中自定义快捷键。

### Q: 截图保存在哪里？
A: 默认保存在桌面的 `Screenshots_日期` 文件夹中，例如 `Screenshots_2024-01-15`。

### Q: 可以截取整个页面吗？
A: 目前只支持可见区域截图。如需全页截图，请滚动页面分段截取。

### Q: 遮罩层挡住了页面内容？
A: 遮罩层使用了 `pointer-events: none`，不会阻止你点击下方的页面元素。

## 权限说明

插件需要以下权限：

- `activeTab`: 访问当前标签页（用于截图）
- `storage`: 保存配置和状态
- `downloads`: 下载截图文件
- `scripting`: 注入内容脚本
- `<all_urls>`: 在所有网页上工作

**隐私承诺**: 本插件不收集任何用户数据，所有截图仅保存在本地。
