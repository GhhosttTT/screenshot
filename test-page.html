📸 Screenshot Extension

测试页面 - 用于验证插件功能

🎯 使用说明

  1. 确保已安装 Screenshot Extension 插件
  2. 按 Ctrl+Shift+Q 激活遮罩层
  3. 在页面上拖拽鼠标选择截图区域（建议选择下方的演示区域）
  4. 按 Ctrl+Shift+S 截图
  5. 点击"下一页"按钮，继续截图测试
  6. 检查桌面的 Screenshots_日期 文件夹

✨ 功能 1

这是一个测试卡片，你可以选择这个区域进行截图。遮罩层不会阻止你点击下方的按钮。

🚀 功能 2

尝试在遮罩层显示时点击这个按钮，验证遮罩层不会阻止交互。

🎨 功能 3

你可以拖拽遮罩层的边缘来调整截图区域的大小。
