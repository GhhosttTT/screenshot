# Screenshot Pro v2.0 - 专业截图录屏工具

## 🎉 新版本特性

Screenshot Pro 是一个**三合一**的专业截图录屏工具，整合了：

1. ✅ **快速截图** - 区域选择 + 批量快速截图
2. ✅ **滚动长图** - 手动滚动拼接成长图
3. ✅ **视频录制** - 标签页录制为 WebM

---

## 📦 安装说明

### 方式一：开发者模式加载

1. 打开 Chrome 浏览器
2. 访问 `chrome://extensions/`
3. 启用右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择 `f:\pluging\ppt-content-extractor` 文件夹
6. 插件安装完成！

## 🎯 功能介绍

### 1. 快速截图模式

**适用场景**: 批量截取固定区域（如 PPT 课件、文档段落）

**快捷键**:
- `Ctrl+Shift+Q` - 激活/停用区域选择器
- `Ctrl+Shift+S` - 快速截图
- `Ctrl+Shift+K` - 锁定/解锁区域（锁定后可点击下方元素）
- `Ctrl+Shift+X` - 清除区域

**使用流程**:
1. 按 `Ctrl+Shift+Q` 激活区域选择器
2. 拖拽鼠标框选截图区域
3. 按 `Ctrl+Shift+S` 快速截图
4. 操作页面（翻页、滚动等）
5. 重复步骤 3 连续截图
6. 所有截图保存到 `PPT_Screenshots/{date-folder}/`

**特色功能**:
- 🔒 锁定模式：锁定后可以点击遮罩层下方的页面元素
- 🎯 调整手柄：8 个手柄（4 角 + 4 边）精确调整区域
- 📁 新建文件夹：一键创建新的会话文件夹
- 🚫 非侵入式：遮罩层不阻止页面交互

---

### 2. 滚动长图模式

**适用场景**: 截取超长页面内容（聊天记录、文章、表格）

**快捷键**:
- `Alt+Shift+S` - 开始/完成滚动截图

**使用流程**:
1. 点击插件图标，切换到"滚动长图"选项卡
2. 点击"打开滚动截图控制台"
3. （可选）点击 `Select Region` 框选区域
4. 点击 `Start` 开始录制
5. 手动滚动页面
6. 按 `Alt+Shift+S` 或点击 `Finish & Save` 完成
7. 自动拼接并保存长图

**高级选项**:
- ✅ 隐藏悬浮元素（吸顶导航、悬浮按钮）
- ✅ 使用当前选定区域（配合快速截图的区域）
- ✅ 自动去重（裁掉重复滚动区域）
- ✅ 内部滚动容器识别（自动检测聊天框、表格等）

**原理说明**:
- 每隔 420ms 自动采样当前视口
- 滚动距离超过 24px 才截取新样本
- 根据滚动坐标自动裁剪重复部分
- 最后拼接成一张完整的长图

---

### 3. 视频录制模式

**适用场景**: 录制操作演示、教程视频

**使用流程**:
1. 点击插件图标，切换到"视频录制"选项卡
2. 选择是否包含标签页声音
3. 点击"打开录制控制台"
4. 点击"开始录制"
5. 操作页面
6. 点击"停止录制"
7. 保存为 WebM 视频

**注意事项**:
- 仅支持普通网页，不支持 Chrome 内部页面
- 保存格式为 WebM（需要 MP4 可用转码工具）
- 录制期间保持录制器窗口打开
- 某些受保护页面（如 Netflix）无法录制

## 📊 统计功能

插件会记录：
- **快速截图次数** - 使用 `Ctrl+Shift+S` 的截图数
- **滚动长图次数** - 完成的长图拼接数

统计数据显示在弹窗顶部，可在设置页面重置。

## ⚙️ 配置选项

右键点击插件图标 → 选项，可以配置：

### 快速截图设置
- 保存路径：桌面或下载文件夹
- 图片格式：PNG 或 JPG
- 图片质量：1-100（仅 JPG）
- 遮罩层颜色：自定义颜色和透明度
- 显示尺寸：是否显示区域尺寸信息

### 滚动长图设置
- 默认隐藏悬浮元素
- 默认使用选定区域
- 采样间隔（毫秒）
- 最小滚动距离（像素）

### 统计管理
- 重置快速截图计数
- 重置滚动长图计数

## 🐛 常见问题

### Q: 快速截图是空白的？
A: 某些网页（如 Chrome 内部页面）不允许截图。请在普通网页上使用。

### Q: 滚动长图拼接不正确？
A: 确保滚动速度不要太快，让插件有足够时间采样。建议匀速滚动。

### Q: 锁定模式有什么用？
A: 锁定后遮罩层边框变绿，隐藏调整手柄，允许你点击遮罩层下方的页面元素（如翻页按钮）。

### Q: 录制的视频没有声音？
A: 检查是否勾选了"包含标签页声音"，并且页面确实有音频输出。

### Q: 可以同时使用快速截图和滚动长图吗？
A: 可以！先用快速截图选择区域，然后在滚动长图中勾选"使用当前选定区域"。

## 🎓 技术栈

- **Chrome Extension Manifest V3**
- **Vanilla JavaScript**（无框架依赖）
- **CSS3**（动画和渐变）
- **Canvas API**（图像裁剪和拼接）
- **MediaRecorder API**（视频录制）
- **Chrome APIs**:
  - `chrome.tabs.captureVisibleTab` - 截图
  - `chrome.downloads.download` - 下载
  - `chrome.storage` - 配置存储
  - `chrome.scripting` - 脚本注入
  - `chrome.tabCapture` - 媒体流捕获
